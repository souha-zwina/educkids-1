🌟 Site d’Apprentissage Dynamique pour Enfants
🎯 Objectif
Développer un site web éducatif et interactif destiné aux enfants, favorisant un apprentissage ludique à travers des contenus multimédias : images, sons,  et textes, organisés par catégories pédagogiques.

📚 Catégories de Contenu
Le site propose plusieurs catégories adaptées à l’apprentissage des enfants :

🔢 Les chiffres – pour apprendre à compter.

🐶 Les animaux et leurs sons – avec des audios pour chaque animal.

🎵 Les instruments de musique et leurs sons – pour éveiller à la musique.

🟦 Les formes et les couleurs .

🚗 Les moyens de transport – visuels + noms + sons associés.
🛠 Fonctionnalités
👩‍💼 Côté Administrateur
Interface simple pour :

➕ Ajouter, ✏ modifier, ❌ supprimer des catégories

Gérer les éléments multimédias (textes, images, vidéos, audios)

Classer chaque élément dans une catégorie

Visualiser un aperçu de chaque média

👦 Côté Utilisateur (Enfants)
Navigation intuitive avec icônes, images colorées et interface adaptée à l’âge.

Lecture facile des sons et vidéos via des boutons clairs.

Découverte des thèmes à travers le jeu et la répétition.

🧑‍💻 Technologies Utilisées
Front-end : HTML, CSS, JavaScript

Back-end : PHP

Base de données : MySQL

Contrôle de version : Git

💾 Base de Données
Entités : catégories, éléments, types de fichiers (audio, vidéo, image), utilisateurs.

Organisation relationnelle simple et efficace.

🤝 Travail Collaboratif
Répartition des rôles : développeur front, back, UI/UX.

Utilisation de Git pour suivre les modifications.

Réunions hebdomadaires pour assurer la cohérence et l’avancement du projet.

🧪 Exemples d'Utilisation
Un enfant clique sur "Les animaux" : il voit des images d'animaux et peut écouter leurs sons.
